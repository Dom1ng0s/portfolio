Como funciona

As cotações são renderizadas inteiramente no browser: dois fetch() paralelos via Promise.all() buscam JSONs públicos do Gado-Scraper direto do GitHub Raw URL. Sem backend, sem proxy, sem chave de API — o GitHub serve os arquivos com CORS aberto. A única dependência é o scraper rodar no GitHub Actions todos os dias às 09:00 UTC e commitar o JSON atualizado no repositório.
