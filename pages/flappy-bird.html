Flappy Bird Clone

Desenvolvimento de Jogos 2D com Unity e C#

Unity (2D URP) C# Game Dev Física 2D

Sobre o Projeto

Este projeto é um clone do clássico jogo Flappy Bird, desenvolvido como parte da introdução a C# e Unity do Laboratório TOCA da UFAL.

O foco principal do desenvolvimento foi a aplicação prática de conceitos fundamentais da engine, saindo da teoria e construindo uma mecânica de jogo funcional do zero.

Mecânicas e Estrutura

A arquitetura do projeto foi dividida para isolar responsabilidades e facilitar a manutenção. O desenvolvimento envolveu a manipulação de física 2D com Rigidbodies e Colliders para o controle do pássaro e detecção exata de impactos.

A geração dos obstáculos (canos) utiliza um sistema de instanciação dinâmica (spawners), criando um fluxo contínuo e aleatório de desafios em diferentes alturas. Além disso, o gerenciamento de estados do jogo garante a contagem de pontos em tempo real e a transição correta para a condição de Game Over.
