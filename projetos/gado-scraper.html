Gado-Scraper

Pipeline diária que coleta as cotações de boi gordo e guarda o histórico no próprio Git.A daily pipeline that scrapes cattle prices and keeps the history in Git itself.

ProblemaProblem

Não existe API pública de cotação de boi gordo no Brasil. Os preços das 33 praças ficam em páginas HTML da Scot Consultoria, e o layout muda com frequência. O Sistema-Gado precisava desses preços todo dia para calcular o valor do rebanho.

There's no public API for cattle prices in Brazil. Prices for 33 markets sit in HTML pages from Scot Consultoria, and the layout changes often. Sistema-Gado needed those prices every day to value the herd.

Git como banco de dadosGit as a database

Um cron do GitHub Actions roda todo dia às 09:00 UTC. Cada execução gera um commit com os JSONs do dia, o que resolve três coisas que um banco exigiria configurar à parte: o histórico não pode ser alterado, a infraestrutura não custa nada e qualquer fork já vem com o histórico completo. Para ver as cotações de um dia, basta git show <hash>:cotacoes_boi_hoje.json.

A GitHub Actions cron job runs every day at 09:00 UTC. Each run produces a commit with that day's JSON files, which covers three things a database would need to be set up for separately: the history can't be altered, the infrastructure is free, and any fork comes with the full history. To see a given day's prices, just run git show <hash>:cotacoes_boi_hoje.json.

Dificuldade: HTML que mudaChallenge: HTML that keeps changing

O ponto frágil de qualquer scraper é onde ele se ancora no HTML. Aqui a âncora é a string "Funrural", uma coluna da tabela que se mantém estável há mais de um ano. As colunas são lidas pela posição, não pelo nome, porque o cabeçalho muda com o layout. Se a coleta falhar, o script tenta de novo até 3 vezes, com 5 segundos entre as tentativas. Se o erro persistir, chega uma notificação no Telegram com o link do log.

The weak point of any scraper is where it anchors to the HTML. Here the anchor is the string "Funrural", a table column that has stayed stable for over a year. Columns are read by position, not by name, because the header changes with the layout. If a run fails, the script retries up to 3 times, 5 seconds apart. If the error persists, a Telegram notification arrives with a link to the log.

ResultadoOutcome

Em 26/06/2026, eram 171 coletas diárias em 181 dias de operação e 5.115 linhas no histórico de boi gordo, uma por praça por dia. Os dados alimentam o Sistema-Gado.

As of 2026-06-26: 171 daily snapshots over 181 days of operation and 5,115 rows of fat-cattle price history, one per market per day. The data feeds Sistema-Gado.
