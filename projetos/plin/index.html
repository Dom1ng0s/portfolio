Plin

Registrar um gasto virou uma mensagem de 5 segundos no Telegram.Logging an expense became a 5-second Telegram message.

ProblemaProblem

Apps de finanças perdem o usuário no atrito: abrir o app, fazer login, achar "nova despesa" e preencher um formulário na fila do mercado. Quem não registra na hora acaba esquecendo. Como o Telegram já está aberto, o Plin transforma o registro numa conversa: gastei 45 reais no mercado vira uma despesa de R$ 45,00 na categoria Mercado. Comecei o projeto por curiosidade, para testar NLP na prática.

Finance apps lose people to friction: open the app, log in, find "new expense", fill in a form while standing in line at the store. If you don't log it right away, you forget. Since Telegram is already open, Plin turns logging into a chat: gastei 45 reais no mercado becomes a R$ 45.00 expense under Groceries. I started it out of curiosity, to try NLP in practice.

Decisões técnicasTechnical decisions

  • NLP híbrido: o spaCy (pt_core_news_sm) faz a lematização, então "gastou", "gastei" e "gastar" contam como a mesma intenção. O valor é extraído por regex, em vários formatos.
  • ID de transação por usuário: cada usuário tem a própria sequência, então /apagar 3 funciona sem expor as chaves globais do banco.
  • Chave primária composta (user_id, id_transacao_user): isola os usuários no nível do banco.
  • Docker Compose: o bot e o banco sobem juntos com um comando.
  • Hybrid NLP: spaCy (pt_core_news_sm) handles lemmatization, so "gastou", "gastei" and "gastar" count as the same intent. The amount is extracted with regex, in several formats.
  • Per-user transaction IDs: each user has their own sequence, so /apagar 3 works without exposing the database's global keys.
  • Composite primary key (user_id, id_transacao_user): isolates users at the database level.
  • Docker Compose: the bot and the database start together with one command.

LimitaçõesLimitations

A classificação é baseada em regras, com o modelo pequeno do spaCy, então frases ambíguas ou gírias podem passar despercebidas. O bot usa SQLite e ainda não tem deploy público.

Classification is rule-based and uses spaCy's small model, so ambiguous phrases or slang can slip through. The bot uses SQLite and has no public deployment yet.
